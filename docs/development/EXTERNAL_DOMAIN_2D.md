# 二维物理域与外部吸收域

2026-10-19：模型、导入/导出和采集几何全部使用物理 NX×NZ 节点，坐标末端为 (N−1)dx。`ExternalDomain2D.h` 仅为 GPU 分配构造扩展副本；边缘材料向外常值延拓，阻尼只在外部生效。自由顶面的镜像行不显示为顶部吸收层。三种原有二维离散格式均走同一映射，三维模块保持独立。

GPUSimData 保存物理尺寸与存储原点。固定/连续震源、接收点索引在 CPU/GPU 交界统一平移；回放及导出裁切回物理域。导入不预先加吸收层，避免重复扩展，密度转换仍保留。快照 manifest 记录 external_pml。

B 仅切换可见范围并适配相机，不释放 GPU 物理场。纹理采样、标尺、网格、源检标记及鼠标拾取共用可见域原点和宽高；浮点纹理保留弱波。按物理区峰值进行显示归一化，显示核不修改物理场。

左键在连续模式下以 0.1 秒操作间隔追加源，不重置求解时间；中键/右键拖动具有持续捕获，优先于源和画笔。正式采集固定单源且锁定配置。

验证：SolverRegression 覆盖三格式外扩域与显式扩展参考的逐点对照、原网格无阻尼、边缘源、接收点平移、浮点显示/峰值参考及回放。真实程序截图检查覆盖 B 键、自由顶面、两种可见范围的拾取、连续源不重置时间、移动/激发互斥和采集导出；同时运行记录 I/O 与三维工作区回归。
