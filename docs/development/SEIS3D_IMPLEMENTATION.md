# Seis3D 实现与使用说明

## 当前实现范围

在当前 `SeisWaveLab_Cartesian` 工程内加入独立三维子系统，保留二维求解器。软件显示名称为 SeisWave Lab，输出程序为 `SeisWaveLab.exe`，CMake 项目为 SeisWaveLab_Cartesian，主程序目标为 SeisWaveLab。版本号统一由 CMake 配置生成 `AppInfo.h` 与 Windows 版本资源。三维 C++/CUDA 类型、函数、状态和算法全部位于 `namespace Seis3D`，以独立静态库目标 `Seis3D` 编译。

```text

├─ include/Seis3D/Common3D.h          物理上下文、GPU 指针、内存预算和视图布局

├─ include/Seis3D/Cuda_Seis3D.cuh        CUDA 求解器接口
├─ src/Seis3D/cuda/Cuda_Seis3D.cu         差分、CPML、自由表面、切片和接收点核函数
```

三维不使用二维的 `ctx`、`gpu_data`、`rec`、`g_replay`、纹理、程序或模拟运行状态。窗口、ImGui/ImPlot 主上下文、界面主题和可执行文件路径查询属于应用层服务。三维内部不创建或销毁主窗口/ImGui 上下文。

首页现在由独立的 `src/SeisCommon/HomeScreen.cpp` 实现，应用层 `AppUi` 库管理主题和导流界面；不再保留三维模块内重复的首页卡片绘制代码。首页包含实际设备信息、双模式入口、流程提示与示意波前动画；窄窗口将双卡片改为纵向布局。下方增加四张流程说明卡、三维网格起步建议和剖面操作指引，入口卡片随可用高度伸展，页脚靠近窗口底部；小窗口允许滚动查看完整内容。

### 双语文字与紧凑分组

`AppLanguage.h/.cpp` 提供应用级英文/简体中文切换，词条集中于 `AppTranslations.inc`；`AppWidgets.h` 为界面控件、帮助文字和自绘标签接入翻译。语言偏好存入程序目录的 `ui_language.ini`。翻译后的可见文字与控件 ID 分离，两种语言使用同一源标签后缀；已有三维窗口的稳定后缀及 DockSpace 宿主 ID 保持原值。旧窗口首次引入稳定后缀时迁移已保存位置和尺寸。未知诊断保留原文，下拉框顺序与物理参数索引不变。

`sectionHeader3D` 统一三维折叠组，`drawSectionTools3D` 为当前面板设置仅本帧有效的展开/收起指令。详细参数默认关闭，常用运行与波场增益默认展开，采集停止按钮与重要错误提示保持可见。语言切换保留折叠状态，展开/收起不触发参数赋值或显示重置。检查和实际截图见 [双语界面与折叠面板检查](../reviews/SEIS3D_BILINGUAL_COMPACT_UI_REVIEW.md)。

批量指令的键由 `sectionCommandKey3D` 使用当前窗口固定 ID 计算，不能使用受标签页 ID 栈影响的 `ImGui::GetID`。工具按钮位于 TabBar 外，`BeginTabItem` 会压入新的 ID；之前两处状态键因此不同，导致模拟控制页的展开/折叠失效。现在按钮与分组共享同一个窗口级指令键，各分组自身的 ID 仍保留标签页作用域；点击只在本帧作用于当前显示的标签页，下一帧恢复独立控制。显示面板使用另一窗口的指令，不互相影响。

### 界面主题

首页右上角提供十套主题：**CUDA Green / Ocean Blue / Graphite / Scientific Light / Midnight Violet / Teal Studio / Amber Lab / Paper Sand / Arctic Lab / Warm Ivory**。其中 Scientific Light、Paper Sand、Arctic Lab 与 Warm Ivory 为浅色主题。三维也可通过 `Workspace > Interface theme` 或 `Display / materials` 切换。主题改变界面背景、文字、控件和停靠标签的颜色，波场和材料配色仍由显示设置独立控制。新增主题追加到原有索引之后，兼容已保存的主题偏好。

`AppUi::FunctionRole` 统一计算绿、震源橙、模型蓝、采集紫、显示青、警告琥珀和危险红。`FunctionStyleScope` 用 RAII 成对推入/弹出控件颜色；普通文字保留高对比前景。首页流程卡、工作区标签、操作按钮、参数分组、滑块和状态文字使用相同语义。主题增加 1 像素控件描边及统一圆角，浅色强调色降低亮度。颜色作用域中切换主题时，退出后重新应用新主题，避免恢复旧主题颜色；旧页面的对比适配作用域也采用相同处理。

主题记录在程序旁 `out/bin/<配置>/ui_theme.ini`，重新启动时加载。无法保存时仍即时应用当前主题，并在选择器悬停提示原因。旧页面在浅色主题下使用局部深色对比适配，保证已有深色波场画布和半透明面板上的文字可读。

## 进入与交互

1. 首页选择 **3D Spatial Exploration Sandbox / 三维空间探索沙盒**。
2. 在 `Simulation3D` 选择网格和材料，点击 **Initialize 3D**。
3. 点击 **Run**，或在 `Source3D` 点击 **Reset wavefield + fire**。
4. 三个切片分别为 X-Z（固定 Y）、Y-Z（固定 X）、X-Y（固定 Z）。滑块或点击切片可以联动交叉线，悬停位置显示物性。鼠标在剖面内滚轮缩放（100%–3200%，以鼠标位置为中心）、中键拖动平移、左键点击联动位置。各剖面分别保存视图；`Reset view` 恢复当前剖面全景，顶部 `Reset views` 恢复三剖面与轨道相机。重置视图保持切片位置与波场不变。
5. 辅助体视图支持左键旋转、右键拖动或滚轮缩放、中键平移。`Display / materials` 可关闭体绘制、切换分量和调整尺度。
6. `Space` 运行/暂停，`C` 重置波场，`R` 重置三剖面与轨道相机，`Tab` 或 **Home / cold switch** 返回首页。体视图也提供独立的 `Reset camera` 按钮。

初始化时同时布设有效的接收系统，默认 100 点。普通 **Run** 会在底部生成实时波形；达到停止步数后按钮变为 **Replay**，点击会从新震源重新计算。**Reset fields** 重置波场并暂停，顶部 **Fire + capture** 则开始正式单炮采集。

剖面缩放使用现有完整分辨率纹理的 UV 窗口，不申请额外三维显存。物理网格、交叉线、震源/接收点和物性坐标拾取共用视图变换；放大后仍按原始格点拾取。缩放和平移被约束在模型范围内；到达边缘时中心会被限制。重新初始化或导入模型会恢复全部相机。

三维按需分配资源，首次进入不自动申请大体积显存。离开模拟页面后，在下一帧绘制前释放该模式的 GPU/GL 资源，避免销毁仍被上一帧 ImGui 指令引用的纹理。目标模式分配之前完成释放。

### 工作区快捷键

应用层无状态 `AppShortcuts.h` 统一屏蔽文本输入、活动控件、弹窗和 Ctrl/Alt/Super 修饰组合，避免 Ctrl+C 清空波场或编辑时误触发。命令使用 ImGui 按下事件且关闭按住重复，不再通过 GLFW 持续按键状态处理二维运行和画笔。二维与三维统一 Q 波场色带、W 分量、E 模型色带；Shift 反向循环。三维 `handleWorkspaceShortcuts3D` 使用已有 `selectWaveComponent3D` 保存同单位的参考和独立压力尺度，色带只改选择索引，不调用视觉预设/显示参数重置。G 网格、B 边界显示、V 体绘制与面板控件使用同样的显示状态；B 同步恢复视图适配，V 同步使抽取缓存失效。N 设置一个求解步，支持暂停时逐步推进采集。C 在采集或多炮序列期间禁用。F1 和顶部 Shortcuts 按钮打开本地双语帮助弹窗；外层路由仍单独处理 Tab 冷切换。完整键位见[使用指南](../user/Seis3D_User_Guide.md)。

### 可停靠工作区与显示样式

顶部 `Workspace` 提供 Four views（四视图）、Volume focus（体视图优先）、Compact / tabbed（紧凑标签页）预设，以及恢复布局、重新打开已关闭窗口的菜单。参数、显示设置、三正交切片、体视图和接收道曲线均为真正的 ImGui 停靠窗口，可拖动标签、拆分、合并和调整大小。三维窗口使用专属 WindowClass，避免与其他模式的窗口混合停靠。

布局由 ImGui 保存到程序旁 `out/bin/<配置>/imgui.ini`；切换预设会重建布局并重新打开窗口。当前不持久化每个窗口的关闭状态和显示参数。参数控件名称位于输入框上方，初始化按钮位于面板顶部，窄窗口可以滚动查看剩余参数。

在 `Display / materials` 中选择：

- **Model + wavefield**：地质模型作为背景，波场按幅值透明叠加，零波场仍能看见材料分层。
- **Wavefield only**：只显示波场。
- **Material only**：只显示 Vp、Vs 或密度。

波场提供二维页面同名的 13 种配色，加上 CUDA Green；包括 Seismic Bipolar、Coolwarm、PuOr、Viridis、Turbo 等。三维采用五个颜色节点插值的近似调色板，并非 Matplotlib 完整查找表或二维着色器的逐像素复制。图例与三维着色器使用同一组颜色节点。幅值、增益、透明度和阈值独立可调；图例显示的是透明混合前的颜色与物理量范围。

提供五套显示预设：**Wavefront contrast / Signed seismic / Geological layers / CUDA glow / Paper scientific**，可在显示面板或 Workspace 菜单中切换。初始选择 Vz、Paper scientific（论文浅色）、Coolwarm 和 Scientific White 浅色材料背景，显示增益 1.8；需要观察全部传播方向时可切换速度幅值。`applyVisualPreset3D` 只切换波场/模型色带，保留分量、组合、增益、尺度、透明度、材料范围和体视图参数，颜色缓存负责即时重绘，不重新抽取数据或清除已观测峰值。红色 `Reset display parameters` 调用 `resetDisplayParameters3D`，显式恢复当前预设的完整显示默认值；字体、主题、轨道相机、物理模型、时间和采集数据保持不变。显示边界关闭后按物理区适配剖面。Paper scientific 重置后的默认效果为 Scientific White 浅色分层、Coolwarm 蓝红波场、速度幅值、增益 1.8、波场透明度 1.0、gamma 0.50；截图入口显式执行重置以获得此效果。`Weak-wave visibility` 仅改变波场透明度的 gamma 映射，`Material background` 调整叠加模式背景亮度；这些选项不修改物理振幅、采集样本或导出数据。纯材料模式仍使用原始材料颜色。

各剖面带有物理坐标标尺和当前分量/单位标签；放大和平移时标尺随 UV 区间更新。四视图的新默认布局为底部曲线分配更多高度；已有用户布局继续保留，可以通过 Workspace 重新应用布局预设。

模型提供 Dark Titanium、Geological Map、Grayscale Velocity、WaveStyle Synced、Scientific White 五种样式，独立选择 Vp / Vs / Density。自动材质范围来自当前抽取的切片和辅助显示体；为比较不同位置或模型，可冻结范围或手动设置。均匀模型使用色带中值，避免零范围除法。模型材质与波场共用 RG32F 显示存储的两个独立通道，不复制完整物理体。

显示每 N 个计算步更新一次可以减少抽取和上传开销；修改切片或物性选择会立即使显示缓存失效。暂停且相机、样式、数据均无变化时跳过重复的离屏绘制。显示数值范围统计按 warp 归约后再执行原子更新，减少线程竞争。这些调整不改变 dt、求解方程或接收点采样间隔，也没有测得可用于承诺的性能提升百分比。

退出三维时可以保留最后一次采集的 CPU 道集以供导出；波场、CPML、接收点 GPU 缓冲、CUDA 流、GL 纹理、着色器和互操作注册均释放。重新进入后需要初始化波场。二维退出时也停止采集/回放并释放二维模拟资源。

## 数值计算

### 常见模型与边界模式（本轮新增）

保留 Uniform / TwoLayer / Sphere / Imported 的既有枚举编号，追加 ThreeLayer、DippingLayer、LowVelocityLayer、Fault、Gradient、SaltDome。模型切换只更新待初始化的物性与几何，重建会话后生效。三层模型等厚，材料采用背景、端点均值、第二介质；梯度模型沿 Z 对 Vp/Vs/rho 端点线性插值。异常半径按各轴网格数归一化，非立方网格中的球预设为椭球。盐丘是底部延伸的合成椭球穹体，不属于实测盐体模型。

几何参数包含界面相对深度、X 向倾斜、夹层相对厚度、垂直断距与异常半径，初始化前检查有限性和范围。程序模型的 CPML/ghost 材料由最近物理单元的坐标生成，避免梯度或倾斜模型继续向域外改变材料。

边界组合为顶部自由表面加五面 CPML、六面 CPML、六面滑移反射壁。`reflecting3D` 开启后 `freeSurface3D=false`，有效 CPML 厚度为零，原厚度作为切回吸收时的设置保留。反射模式不分配记忆变量或系数，导数直接进入弹性更新。

反射壁满足法向速度为零、切向牵引力为零，属于滑移对称壁；参见[自由滑移边界的条件说明](https://se.copernicus.org/articles/13/583/2022/se-13-583-2022.html)。这不等同于全自由表面或三分量速度均固定的刚性夹持。壁面位于物理节点外半格处。`reflectingGhostKernel3D` 按字段的整数/半整数位置做镜像：法向速度和含法向的剪切应力奇对称，其余偶对称，半格边界节点显式置零。三个轴在同一 CUDA 流顺序处理，角点由各轴反射组合。

### 边界显示与字号（本轮新增）

显示布局缓存完整活动网格（物理区与 CPML，不含 ghost），只增加切片和有界显示体的缓冲，不复制完整计算体。开关隐藏时 UV 裁切物理区域，开启时显示实际 CPML 数据。物理区与 CPML 的标记、标尺、缩放、拾取使用一致映射；CPML 悬停不执行物性查询或联动域外坐标。体绘制用独立 UV 范围选择区域，并区分内层物理包围盒和外层 CPML 包围盒。材料范围使用物理格点；波幅统计在显示 CPML 时包含吸收区。默认保留当前分量的已观测峰值，也可选逐帧自动尺度；该峰值来自抽取视图，不是每步全体积归约。

三维默认字体恢复为应用的 21 像素（此前乘 0.86），支持 0.85–1.25 倍工作区缩放；标尺字号为工作区的 0.76 倍。参数按网格、边界、模型、时间稳定性折叠，预设参数列宽为当前字号的 23 倍；保留已有 ImGui 布局，重新应用预设才调整列宽。工具栏依据剩余宽度换行。

以下原有算法说明继续适用于吸收与自由表面配置。

- 三维各向同性一阶速度—应力方程，3 个速度分量和 6 个对称应力分量。
- X 为显存连续维度。物理网格外增加 CPML 与 4 层差分 ghost cells，界面尺寸和导出模型均不包含这些填充层。
- 固定八阶交错一阶空间差分，权重 `1225/1024, -245/3072, 49/5120, -5/7168`。每个方向使用 8 个采样点，三方向形成 24 点十字邻域。
- 二阶 leapfrog 时间推进；速度位于半时间步，应力位于整数时间步。
- 速度点使用面中心平均密度；剪切点使用四单元调和平均剪切模量，零剪切模量不会被自动改成固体。
- 震源采用归一化 3×3×3 空间分布和 Ricker 时间函数。爆炸源幅值为应力率 Pa/s，体力源为 N/m³；不是未经标定即可解释为地震矩的震源参数。

主频输入保存到 `editContext3D`，当前实际运行值在 `context3D`。应用主频/重发/新采集调用 `applySourceFrequency3D`，以实际模型验证候选上下文，仅提交频率，不应用其他草稿。`refreshCpmlCoefficients3D` 使用相同系数生成器先分配并上传三轴候选数组，全部成功后替换旧系数；反射模式无需 CPML 数组。随后重置动态场和 CPML 记忆变量。新炮在主频提交之后冻结上下文，已完成炮集不被修改，显示增益保留。采集中不同频率被拒绝；多炮同频重启正常。主频不参与 CFL 速度上限，时间分辨率与记录 Nyquist/时长约束另在 UI 提示。

2026-10-14 默认参数与主频迭代检查：RelWithDebInfo / Debug 主程序构建通过；工作区回归验证 300×50×300、1000 样点缓存、三排各 50 道、300 道 GPU 部署/采样和 301 道拒绝。500×20×500 / 200³ 的 CPU 预算检查通过，未以该检查声称已完整运行两个大模型。三轴主频更新系数与同主频全新 GPU 初始化逐值相同；非法主频拒绝、其他草稿隔离、源/增益/旧炮集保持、采集锁定与多炮同频重启通过。真实主程序显示检查继续使用显式 96³ / 100 道小算例并通过，不受新的交互默认尺寸影响。
- 爆炸源注入法向应力；体力源按三方向向量注入速度更新。

### CPML

使用非分裂卷积记忆变量：`psi = b * psi + a * derivative`，`filtered = derivative/kappa + psi`。

每个方向有 6 个独立导数记忆槽，仅在该方向的 CPML 薄层分配，角点同时拥有各自方向的记忆。普通物理区不保存 PML 记忆。中心和半格点分别生成系数；自由表面开启后，不分配顶部 Z 向 CPML。

当前固定参数：三次阻尼轮廓、目标反射参数 `1e-6`、`kappaMax=3`、`alphaMax=pi*f0`。这里的 `1e-6` 是系数设计参数，**不代表实测反射系数**。算法依据见 [Komatitsch 与 Martin 的 CPML 资料](https://specfem.org/komatitsch.free.fr/README_seismic_cpml.html)；实现使用独立编写的 CUDA 代码。

### 平面自由表面

物理顶面为 Z=0，对应填充网格 k=4。`sigma_zz` 在整数面置零并做奇对称镜像；`sigma_xz`、`sigma_yz` 按各自的半格位置做奇对称镜像，牵引力在物理表面插值为零。

速度 ghost 映射满足：

```text
d(vx)/dz = -d(vz)/dx
d(vy)/dz = -d(vz)/dy
d(vz)/dz = -lambda/(lambda+2*mu) * (d(vx)/dx+d(vy)/dy)
```

表面 Vz 使用首两个半格点做二阶外推；表面法向应力更新同步施加同一约束。**内部空间八阶，平面表面闭合二阶**。当前不支持起伏地形、曲面自由表面或全局八阶表面闭合。

### 安全时步与输入防御

`S=sum(abs(staggeredWeights))`，采用：

```text
safeDt = cflSafety * spacing / (sqrt(3) * maxVp * S)
safeDtUs = floor(safeDt * 1e6)
dtUs = manualTimeStep ? round(requestedDtMs * 1000) : safeDtUs
dt = dtUs / 1e6
```

默认安全系数 0.85，最大允许 0.9。时步向下量化到整数微秒。量化后不足 1 微秒，或超过实现时步范围 65535 微秒时明确拒绝初始化。采集时另行检查 SEG-Y rev1 的正有符号二字节范围，实际抽取间隔不得超过 32767 微秒。

`SimulationContext3D.manualTimeStep3D` 默认关闭，`requestedDtMs3D` 默认 0.5，仅作为手动模式的预填值；`safeDt3D` 存放量化后的安全上限，`dt3D` 存放最终求解时步。手动输入要求有限、1～65535 整数微秒且不大于 `safeDtUs`，只容许浮点输入的微小舍入误差。超限直接拒绝，不偷偷回退自动值。初始化/重建在释放旧资源前完成验证，采集及多炮序列禁止重建。模型导入预检只校验维度与预算，扫描真实最大 Vp 后再验证手动时步，避免使用旧模型的最大速度误判。

界面在 TIME / STABILITY 提供模式选择、ms 输入、0.25/0.5/1 ms 按钮、安全上限、候选与已生效步长以及采样间隔预览。步长属于重建参数：Run、重置波场、应用主频、开始采集都保留已生效步长，未重建的编辑保持待应用。重建时 CPML 系数按新时步重新生成；只应用主频时从实际上下文复制时步，不合并待应用步长或模型参数。显示增益和色带不由时步控件重置。

正式道集冻结其自身 dt，SEG-Y 间隔按 `round(dt*1e6)*stride` 编码。名义窗口 `N*stride*dt` 与实际首末时间跨度 `(N-1)*stride*dt` 分别使用，首样点仍为 `(stride-0.5)*dt`。0.5 ms、stride=2、1000 样点得到 1 ms 间隔，名义窗口 1 s，实际样本从 0.75 ms 到 999.75 ms。

导入模型先逐单元检查 Vp/Vs/rho，并扫描最大 Vp；拒绝非有限数、非正密度和非正体积模量。GPU 更新检测非有限波场并暂停三维工作区，不继续导出损坏样本。

## 显存预算

以下为物理节点数，CPML=12，平面自由表面开启，包含填充网格、九个物理场、三个材料场、CPML、显示纹理和 staging 的**代码预算估算**：

| 网格 | 场与材料 | CPML | 总预算 |
|---|---:|---:|---:|
| 96³ | 0.085 GiB | 0.020 GiB | 0.140 GiB |
| 160³ | 0.297 GiB | 0.047 GiB | 0.443 GiB |
| 300³ | 1.577 GiB | 0.144 GiB | 1.987 GiB |
| 300×300×400 | 2.070 GiB | 0.179 GiB | 2.516 GiB |

预算硬上限 4 GiB。分配前查询实际剩余显存，并额外保留 `max(512 MiB, 设备总显存的20%)`。驱动、显示系统和 CUDA 模块另有占用，实际剩余量以顶部状态栏为准。

三正交切片使用完整网格抽取；体绘制使用每轴最多 256 点的 RG32F 显示体，按体素中心三线性重采样，避免复制完整三维计算体。显示体为探索性采样，可能遗漏薄层和细小高频波前，不用于振幅测量。输出随视口和 framebuffer scale 调整，最长边 1536 像素，预算预留完整 1536² RGBA8 目标；保持纹理 ID 原位调整存储，暂停状态下改变窗口大小也会重绘。射线采样根据可见体素路径自适应为 192–1024 点，并采用正确宽高比投影。CUDA/GL 互操作使用独立注册的 PBO，映射和解除映射使用三维自己的 CUDA 流；参考 [NVIDIA 互操作文档](https://docs.nvidia.com/cuda/cuda-programming-guide/04-special-topics/graphics-interop.html)。

尺寸验证将固定 512 单边限制改为每轴至少 16、物理总量最多 36,000,000。乘积检查采用先除后乘以拒绝溢出的模型文件；CPML、ghost 和显示资源仍计入显存预算。图形初始化检查实际 GL_MAX_TEXTURE_SIZE，硬件不支持的长轴会明确报错。600×24×20 的实际 CUDA/GL 初始化、推进和 256 点重采样已加入检查；600×200×200 与 300×300×400 的总量验证不分配大体积显存。

默认限制每帧 1–8 个时间步，防止 GPU 工作无限排队。300³/300×300×400 的实际 FPS 依赖 GPU、构建配置、切片/体绘制开销，当前没有实测帧率承诺。

## 三维采集与 SEG-Y

### 实时波形与正式采集

底部预览可选择 **Auto / Live / Capture / Imported**。普通运行按每个计算批次抽取 Vx/Vy/Vz，保存实际半时间步时间戳，每道最多保留最近 1000 个预览点，接收总上限为 500，道数与缓存时长独立。默认 500 道的浮点样本为 6,000,000 字节，另有 8000 字节共享时间戳，总计约 5.73 MiB。该监视序列可用于观察信号到达，不作为等间隔正式道集导出；Imported 独立读取外部单炮文件。

512 点增至 1000 点仅改变主机环形缓存容量，不增加正演计算步数、GPU 接收采样频率或每批次传输宽度。满缓存时波形处理/绘制的点数约增为 1.95 倍，AGC 与同时可见道数会影响实际 UI 开销；未据此推断整个软件帧率下降比例。时间窗随 dt 与每批次步数变化，不是固定秒数。

正式采集仍按指定 stride 记录每道样本，冻结采集几何，保存独立 CPU 快照。开始正式采集会清空实时预览；后续普通 Run、Replay 和实时环形缓冲不会覆盖已有正式道集。Auto 在正式采集或暂停且有道集时显示 Captured，否则显示 Live。接收点滑块可切换预览位置；未到波时给出提示。绘图最多显示 2048 个抽取点，不减少保存或导出的样本。

`Data Acquisition 3D` 支持：

- 按 XYZ 原点、XY 节点数和间距布设接收网格，**默认 100×5＝500 个接收点，总上限 500**；Z=0 表示地表，较小网格适配时可减少实际数量。
- 道数按 `receiverCountX × receiverCountY` 计算，默认 100×5 共 500 道，另有 50×3、50×6 及原有小规模预设。界面调整数量时约束总数；采集配置与 CUDA 接收点 API 拒绝超过 500 道，失败时保留此前有效的接收系统。数量限制以外，布设范围仍必须落在模型中。
- 每个接收点同时记录 Vx/Vy/Vz；每个分量的 SEG-Y 文件最多包含 500 道，三个分量导出为三个文件。每炮默认 1000 样点，stride=2；记录窗口的抽稀/选道不改变原始采样数量。
- 默认单炮激发，多炮布设的每线炮数与源线数均为 1；可按首炮 XYZ、每线炮数、源线数和 XY 间距设置矩形多测线震源，逐炮重置和采集。
- 单炮最多 32767 样本，实际采样间隔最多 32767 微秒，三分量 CPU 缓冲上限 512 MiB。采集期间冻结模型、震源、观测系统和时步。
- 接收值为面中心速度在单元中心的空间插值。步长 stride 采样，首样本时间为 `(stride-0.5)*dt`，后续间隔为 `stride*dt`。
- 每炮输出 `_vx.sgy`、`_vy.sgy`、`_vz.sgy` 和 `_geometry.csv`，多炮输出到独立会话目录；失败时保留 CPU 道集供重试。
- 主体采集和文件 I/O 当前在 UI 线程驱动；大文件导入/导出期间界面可能短暂停顿。尚未实现后台文件队列或无限时长采集。

依据 [SEG-Y rev1 官方标准](https://seg.org/wp-content/uploads/2025/11/seg_y_rev1.pdf)，采用 ASCII 文本头、400 字节二进制头、240 字节道头及大端 IEEE float32 样本。明确标记共炮点排序。

| 道头字节（从1计数） | 内容 |
|---|---|
| 9–12 / 13–16 | 炮号 / 炮内道号 |
| 29–30 | 三分量标识：Vx=Inline(14)，Vy=Crossline(13)，Vz=Vertical(12) |
| 69–70 | 高程比例因子 -1000 |
| 71–72 | 坐标比例因子，自动选用 -1000/-100/-10/1 防止大坐标溢出 |
| 73–76 / 77–80 | 源点 Sx / Sy |
| 81–84 / 85–88 | 接收点 Gx / Gy |
| 89–90 | 坐标单位：长度，文件测量单位为米 |
| 109–110 / 215–216 | 首样本延迟 / 时间比例因子 |
| 115–116 / 117–118 | 样本数 / 采样间隔，微秒 |
| 181–184 / 185–188 | 源检中点 XY |
| 189–192 / 193–196 | CMP Inline（Y方向分箱）/ Crossline（X方向分箱） |
| 203–204 | 道值单位：m/s |

CMP 分箱以模型物理 XY 原点为起点，使用源检中点和指定的 XY 箱宽，一起加上世界坐标原点偏移。当前是局部直角坐标加原点偏移，**不执行投影坐标转换、旋转测网变换、CMP 叠加或偏移成像**。

SEG-Y 的首样本延迟字段采用允许范围内尽可能精细的十进制时间比例。若量化不能精确表达半时间步，文本头和 CSV 仍保留精确起点；需要精确对时的软件应读取 CSV。部分老软件忽略道头时间比例，导入时需要自行设置首样本时间。

## .s3dm 模型格式

完整字段定义、字节序与轴约定、版本兼容和独立 Python/C++ 读取器见 [S3DM 模型格式与独立读取说明](../user/S3DM_Model_Format.md)。本格式由项目自定义，不是通用地震数据标准，也不包含完整模拟会话。

采用 Windows x64 小端 IEEE float32 物性体，36 字节头：

```text
0..7    magic = "S3DMOD1\0"
8..11   uint32 version = 1 or 2
12..15  uint32 nx
16..19  uint32 ny
20..23  uint32 nz
24..27  uint32 CPML thickness
28..31  uint32 boundary (0: six CPML, 1: free top, 2: slip reflecting walls)
32..35  float32 spacing in metres
36..    float32 triples [Vp, Vs, rho], X fastest, then Y, then Z
```

只有物理单元写入模型文件，CPML/ghost 材料由边缘外推生成。频率、震源与观测系统不保存在此模型格式中。导出模型需要指定新文件名；使用临时文件完成写入后才改为正式文件名。

版本 1 仅允许边界码 0/1；反射模型导出为版本 2，头长和材料排列不变。新版读取器兼容版本 1，旧程序不能读取反射模式的版本 2 文件。其他模式继续导出版本 1。

### 显示参数生命周期与多道选行

`initializeSession3D`、`restartSimulation3D` 仅清零旧波场统计，保留显示设置。`setAutomaticScale3D` 在自动转手动且当前分量有有效统计时复制有效参考值，避免切换模式突变；无有效波场时不覆盖已有手动值。`displayScale3D` 与着色器一致地使用不小于 1e-12 的有效尺度。统一重置显示参数仍是独立的显式动作。

`selectReceiverRow3D` 按实际接收点的固定 Y/Z 或 X/Z 分组并沿活动方向排序，不依赖正在编辑的 Survey 尺寸；Captured 使用 Gather 中冻结的坐标，Live 使用已部署坐标。`buildTraceSeries3D` 按正式采样时间或实时环形时间构造有界预览，超过 2048 点时保留区间极值和端点，峰值统计覆盖全部所选原始样本。多道图使用 ImPlot 变面积波形，时间轴向下，Trace gain 与物理波场显示增益独立。共同归一化作用于当前所选道；逐道归一化明确提示失去道间振幅可比性。

新增 Receiver focus 停靠预设与四种道集视图。初始化、重建、导入、三种边界、震源与采集生命周期，以及实际渲染和接收排列的验证条件见 [显示状态与接收选行检查](../reviews/SEIS3D_DISPLAY_STATE_RECEIVER_REVIEW.md)。

### 分量共用尺度与单炮文件导入

Vx/Vy/Vz/速度幅值的自动归一化改为共同的速度幅值参考。CUDA 抽取时同步统计该值，诊断缓冲由 4 个扩为 5 个 uint32，原有错误和材料统计位置不变；不新增计算体，也不修改求解方程。`viewMaximum3D` 保留所选分量的实际最大值，`referenceMaximum3D` 提供当前单位的显示参考。`selectWaveComponent3D` 保持同单位的峰值与手动尺度，并在速度 m/s 与压力 Pa 之间切换独立缓存。初始化/重新发射清空两个旧波场峰值，保留显示设置。

`ImportedShot3D` 为独立 CPU 数据，保存原始坐标、道号、逐道起点与实际分量/单位。导入在临时对象中完整检查后提交，不调用会中断计算的动作包装器。解析支持大端 rev0/rev1 的格式码 1/2/3/5/8，拒绝多炮、混合分量/单位、变长道、非有限样本及超预算输入。坐标的整数排序键只用于排列分组；图中显示原始坐标，不将外部坐标舍入到模拟网格。全部道显示按实际数据总道数更新，不再固定为 128 道；手动范围上限为剩余道数，单排按真实坐标选择。每道预览最多 2048 点，完整样本保留。单文件只显示其实际分量，不合成其余分量为零。

显示缓存按实际接收数量允许最多四个分量的条目，避免显示 150/300 道时每达到 128 条就清空并反复执行 AGC。新数据、时间元数据或 AGC 参数改变仍使缓存失效。实际 CPU 预览内存和绘图量随可见道数增长；当前导入自身仍限制 4096 道和 256 MiB 原始三分量存储，并未引入后台预处理。

导出后重新导入、数据格式、失败回滚及实际图形检查见 [分量尺度与单炮导入检查](../reviews/SEIS3D_COMPONENT_SCALE_SHOT_IMPORT_REVIEW.md)。文件解析在 UI 线程完成，大记录加载时可能短暂停顿；Windows 文件选择对话框未做自动交互测试。
