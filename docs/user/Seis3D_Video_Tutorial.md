# Seis3D 模型到采集与 AGC 视频教程

本教程使用 OBS Studio 录制实际 Seis3D 程序界面。演示模型设置、震源、接收排列、单炮采集、地震记录自动增益补偿，以及 SEG-Y 导出。录像使用 **Paper Sand** 浅色主题、96³ 双层模型、10 × 10 地表接收网格、256 个样本和采样步距 2。为缩短界面停留时间，成片以 4 倍速呈现，并在画面下方添加中文字幕；音轨静音。录像约 2 分 33 秒。

录像保留录制时的 96³、10×10 演示排列。当前程序初始网格为 300×50×300，接收排列为 X 向每排100道、Y向5排，共500道，接收上限500道；默认单炮激发，每炮1000样点。初始波场为 Vz，视觉预设为论文浅色（Paper scientific），材料为 Scientific White，色带为 Coolwarm，显示增益1.8，历史峰值保持关闭。导出位置与文件名前缀控件见完整指南第 8、9 节。

## AGC 参数说明

在 **地震记录 → 波形选项** 中启用 **自动增益补偿（AGC）**。默认时间窗 120 ms、强度 1.00、最大放大量 50×、噪声门限为该道原始峰值的 0.01%。时间窗采用居中的局部 RMS；增大强度会强化较弱的时段，降低最大放大量或提高噪声门限可减少背景噪声被抬高。此处理仅针对预览，录像最后导出的 SEG-Y 仍保存原始采样。

演示导出的文件默认位于外层 `out/bin/RelWithDebInfo/data_Seis3D/capture_<时间戳>`。每炮包含 Vx、Vy、Vz 三个 SEG-Y 文件和几何 CSV。成片已内嵌中文字幕；同名 `.srt` 文件用于查看或改写字幕时间轴。
